🎃 What is Hacktoberfest 2026?

Hacktoberfest is an annual open source contribution event running throughout October. Contributors earn a limited-edition digital reward (and sometimes real money) by submitting quality pull requests to participating repositories. Hacktoberfest 2026 runs from October 1–31.

💰 Paid Bounties ($1 per merged PR)

Some repositories like NextCommunity and john-bampton pay $1 USD per merged PR via GitHub Sponsors. Look for issues labeled $1, bounty, or paid. Use the "Bounties only" filter above to find them.

Tips for Getting Your PRs Merged

  • Read the contribution guidelines before submitting
  • Keep PRs focused — one change per PR is easier to review
  • Request assignment first — many maintainers won't review unassigned PRs
  • Follow the existing code style and pass all CI checks
  • Be patient — maintainers are volunteers. Politely follow up after 5–7 days
